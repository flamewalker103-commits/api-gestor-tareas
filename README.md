# API Gestor Tareas

Bienvenido a **API Gestor Tareas**. Este proyecto tiene como objetivo proporcionar una API RESTful para gestionar tareas diarias utilizando el enfoque de desarrollo guiado por pruebas (TDD).

## Características
- Crear tareas
- Listar tareas
- Actualizar tareas
- Eliminar tareas

## Requisitos
- Node.js
- npm

## Instalación
1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/api-gestor-tareas.git
   cd api-gestor-tareas
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```

## Cómo ejecutar la API
```bash
npm start
```
La API estará disponible en `http://localhost:3000`.

## Pruebas
Para ejecutar las pruebas, utiliza:
```bash
npm test
```
